A personal file manager for Windows

Waypoint

Waypoint is a file manager for Windows with a game-style look: folders become places you travel to, files get a rarity, and tidying up earns experience. It runs as a desktop app on the user’s own PC. It is a personal project, made for its author’s own use, and it is not sold or offered as a service.

The Mail tab

Waypoint can show and tidy the user’s own Gmail inside the app. It signs in through Google’s own sign-in page and asks for two permissions (Google calls them scopes): gmail.modify (read, label, archive, move to Gmail’s Bin, keep drafts and send mail) and gmail.settings.basic (Gmail filters, used for Mute and Block). It never permanently deletes mail. It only does these things when the user asks for them, for example by pressing Send, Archive or Mute.

  • Everything stays on the user’s PC. Mail is fetched straight from Google to the app and shown there. There is no Waypoint server.
  • The sign-in key is kept in Windows Credential Manager on that PC, never in a cloud folder.
  • Access can be removed at any time: Mail → Accounts → Sign out in Waypoint, or myaccount.google.com/connections (details in the privacy policy below).
  • Pictures from the internet inside mail stay blocked until the user chooses to show them.
